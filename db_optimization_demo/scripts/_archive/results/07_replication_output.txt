[4] 多线程并行复制配置（MySQL 8.0 LOGICAL_CLOCK）
  当前并行复制配置:
    replica_parallel_type: LOGICAL_CLOCK
    replica_parallel_workers: 4

  📋 在从库执行以下命令开启并行复制:
    mysql> STOP REPLICA;
    mysql> SET GLOBAL replica_parallel_workers = 8;
    mysql> SET GLOBAL replica_parallel_type = 'LOGICAL_CLOCK';
    mysql> SET GLOBAL binlog_transaction_dependency_tracking = 'WRITESET';
    mysql> START REPLICA;

  ✅ LOGICAL_CLOCK: 主库组提交的事务可并行回放，
     大促写入激增时，延迟可从 120s+ 降至 <5s

[5] 读写分离延迟感知（业务层方案）

  方案3: 延迟感知中间件（如 ShardingSphere-proxy）
         → 延迟超阈值自动切主库
  方案4: 业务侧 5s 快速失败 + 重试，避免用户感知
