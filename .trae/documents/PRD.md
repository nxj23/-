# 校园运动会管理系统 — 产品需求文档（PRD）

## 1. 产品概述

校园运动会管理系统是一款面向学校体育赛事的全流程数字化管理平台，覆盖赛事发布、学生报名、成绩录入、排名统计、公告通知等核心环节，服务于教师（赛事组织者）与学生（参赛者）两类角色，旨在提升运动会组织效率、保障数据准确、激发校园运动参与氛围。

- **目标用户**：中学/高校体育教师、班主任、在校学生
- **核心价值**：将传统纸质/Excel 的运动会管理流程数字化，实现报名在线化、成绩实时化、统计自动化、通知即时化
- **目标平台**：Web 端，PC 与平板自适应

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册/登录方式 | 核心权限 |
|------|---------------|----------|
| 教师 | 工号 + 密码（管理员预设账号） | 赛事发布、报名审批、成绩录入、赛程编排、公告发布、数据统计查看 |
| 学生 | 学号 + 密码（管理员预设账号） | 项目报名、成绩查询、赛程查看、公告接收、个人中心管理 |

### 2.2 功能模块

1. **登录与角色路由** — 统一登录入口，根据角色跳转教师端或学生端
2. **赛事管理（教师）** — 运动会项目 CRUD（田径、球类、趣味项目），设置名额、时间、场地
3. **报名审批（教师）** — 查看报名列表，通过/驳回，冲突检测提示
4. **成绩录入（教师）** — 按项目录入成绩，自动排名、破纪录标记、成绩导出
5. **赛程安排（教师）** — 时间场地编排、分组抽签、赛程表生成
6. **公告管理（教师）** — 发布系统公告、定向消息推送
7. **数据统计（教师）** — 班级/年级积分榜、个人奖牌榜、项目参与率
8. **项目报名（学生）** — 浏览可报项目、在线报名、冲突提示
9. **成绩查询（学生）** — 查看个人成绩、排名、破纪录标识
10. **我的赛程（学生）** — 个人参赛时间表
11. **公告通知（学生）** — 系统公告与个人消息
12. **个人中心（学生）** — 个人信息、报名历史、成绩证书

## 3. 核心流程

**学生报名流程**：学生登录 → 浏览可报项目 → 点击报名 → 系统校验名额与时间冲突 → 提交报名申请 → 教师审批 → 报名成功通知 → 进入个人赛程。

**成绩录入流程**：教师进入成绩录入 → 选择项目 → 录入各选手成绩 → 系统自动排名 → 检测破纪录 → 保存并发布 → 学生端实时查看 → 更新积分榜与奖牌榜。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：运动蓝 `#2563EB`（主操作/链接）+ 活力橙 `#F97316`（强调/奖牌/破纪录）+ 纯净白 `#FFFFFF`（背景）
- **辅助色**：赛场绿 `#10B981`（成功/通过）、警示红 `#EF4444`（驳回/冲突）、金牌黄 `#FBBF24`、银牌灰 `#9CA3AF`、铜牌棕 `#B45309`
- **字体**：中文 `Noto Sans SC`，英文/数字 `Inter`，标题加粗有力，数字使用等宽变体突出成绩
- **按钮风格**：圆角 8px，主按钮蓝底白字带轻微阴影，次按钮白底蓝字蓝边
- **布局风格**：左侧固定侧边栏导航 + 顶部状态栏 + 主内容区卡片式布局；学生端首页采用大卡片+图表组合
- **图标风格**：线性图标（lucide-vue-next），运动主题（跑步、奖杯、秒表、奖牌）
- **动效**：页面切换 slide-fade、数据更新计数动画、奖牌弹跳、破纪录闪烁、卡片悬浮上浮

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 登录页 | 登录卡片 | 左侧运动主题插画/渐变背景，右侧白色登录卡片，渐变按钮，输入框带图标 |
| 教师端-工作台 | 数据卡片 | 四宫格统计卡（待审批/待录入/今日赛程/公告），渐变图标，数字计数动画 |

| 教师端-数据统计 | 排行榜样式 | 前三名奖牌领奖台造型，柱状图/环形图，班级头像组 |
| 学生端-首页 | 概览大卡 | 顶部欢迎横幅渐变背景，下方四模块快捷入口卡片 |

### 4.3 响应式

- **桌面优先**：默认 1280px+ 设计，侧边栏 + 多列布局
- **平板自适应**：768-1280px，侧边栏可折叠为图标模式，卡片网格自适应 2 列
- **触控优化**：按钮最小 44px 触控目标，表格横向滚动，关键操作悬浮固定

### 4.4 3D 场景指引

本项目不涉及 3D 场景，采用 2D 插画 + 渐变 + 动效营造运动氛围。
